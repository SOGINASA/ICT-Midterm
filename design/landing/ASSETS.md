# TengeFlow landing illustrations

Created on 2026-10-01 with the built-in image_gen tool. Art direction references the illustrated, restrained presentation of https://erik-hazel.vercel.app; all three pictures are original generated assets, not copied artwork.

Production exports are in `public/images/landing/`: `almaty-everyday-{640,1024,1536}.webp`, `cafe-moments-{640,1024,1536}.webp`, `quiet-plans-{640,1024,1536}.webp`. Original PNGs are preserved in `design/landing/originals/`. WebP exports use cwebp quality 85, with no artistic modifications. Responsive srcset, reserved dimensions and lazy loading for secondary pictures are set in LandingPage.tsx.

The landing styles are scoped separately from the finance workspace and account pages. The product preview uses sample values from the existing demo dataset. No bank integrations, user reviews, or live account availability are implied by the artwork.
